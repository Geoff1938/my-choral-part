# MyChoralPart Branding Package

## Quick Start

This folder contains everything you need for consistent MyChoralPart branding.

### For Claude Code:
1. Drop this entire folder into your project
2. Read `BRANDING_GUIDE.md` for complete specifications
3. Reference logo files from this folder in your code
4. Use the CSS variables provided in the guide

### What's Inside:
- **BRANDING_GUIDE.md** - Complete design system (colors, fonts, spacing, components)
- **SVG logos** - Scalable versions (use these when possible)
- **PNG logos** - Pre-rendered at multiple sizes (16px to 1024px)

### Most Common Files You'll Need:
- `logo-icon-32.png` - For favicon
- `logo-horizontal.svg` - For app header
- `logo-icon-only.svg` - For app icons
- CSS variables in BRANDING_GUIDE.md - For styling

### Voice Part Colors (Copy-Paste):
```css
--color-soprano: #E74C3C;  /* Red */
--color-alto: #3498DB;     /* Blue */
--color-tenor: #2ECC71;    /* Green */
--color-bass: #9B59B6;     /* Purple */
--color-highlight: #F39C12; /* Orange - for active/selected */
```

For full details, open BRANDING_GUIDE.md
